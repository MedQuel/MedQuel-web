# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email `support@medquel.com` with a clear description, reproduction steps, affected URLs or files, and the potential impact.

Allow reasonable time for investigation and remediation before public disclosure. Do not include passwords, access tokens, private user data, or other secrets in reports.

## Scope

This policy covers the MedQuel public website and its deployment configuration. API and mobile-client issues should be reported to their respective repositories as well.
